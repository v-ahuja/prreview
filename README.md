# prreview

PR Walkthrough is a GitHub-connected review workspace with a PR inbox, team collaboration, manual walkthrough generation with harness/model selection, a GitHub-style diff view, linked code, an embedded editor, Markdown/Mermaid/Excalidraw, and contextual chat. It also includes a local CLI and a credential-free interactive demo. The redesign follows the Notion spec, excluding the later agent-memory feature.

See [the app README](app/README.md) for setup and development instructions.
